# Logo files

- `mark.jpg` — the full uploaded logo (monogram + "dreamsEnvisioned" text on
  a black circle), kept as the source reference. Not used directly on the
  site.
- `mark-icon.png` — the monogram cropped out on its own, transparent
  background. This is what the site actually renders in the header, hero,
  and footer.

If you upload a new/updated logo, replace `mark.jpg` and re-crop a
transparent `mark-icon.png` (monogram only, no wordmark baked in, tight
bounding box) to keep the site in sync.
