# Logo files

Reference copies of the DreamsEnvisioned logo, for use outside the website
(email signatures, press kit, social profile photo, printed materials).

Suggested files:

- `logo/dreamsenvisioned-mark.svg` — icon/mark only
- `logo/dreamsenvisioned-lockup.svg` — full lockup (mark + wordmark)
- `logo/dreamsenvisioned-lockup-light.png`, `logo/dreamsenvisioned-lockup-dark.png`
  — flattened raster versions for places that don't accept SVG

The website header itself renders the brand name as live text (Fraunces
typeface) rather than an image, so nothing here needs to change for the
site to work — these are just for external use.
