# Hero background reel

Upload here, using these exact filenames — the homepage picks them up
automatically, no code changes needed:

- `reel.mp4` — looping background video behind the hero wordmark (muted,
  ideally 1920×1080+, H.264, under ~15MB)
- `poster.jpg` — a single frame shown while the video loads

Until `reel.mp4` exists, the hero shows its gradient placeholder instead.
